# AI Usage Statement  
## CS665 Project 3 — Generative AI Acknowledgement

## Overview

Generative AI tools such as ChatGPT and Codex were used during this project as learning and debugging assistants. AI was not used as a replacement for understanding or completing the project independently. Instead, it was used to clarify unfamiliar topics, troubleshoot errors, improve documentation wording, and provide guidance when working through full-stack development concepts.

All code, documentation, and design choices were reviewed, modified, and tested before being included in the final project.

## 1. Understanding Flask and SQLAlchemy

**Tool Used:** ChatGPT / Codex

### Purpose

AI was used to better understand how Flask and SQLAlchemy work together in a full-stack application. Since this project required connecting a Python backend to a relational database, AI helped explain the general purpose of routes, models, templates, and database sessions.

### Topics Discussed

- Flask route structure
- GET and POST requests
- SQLAlchemy models
- Database relationships
- Jinja2 templates
- How backend data is displayed on frontend pages

### Personal Contribution

The database tables and relationships were based on the pet adoption database design used for this project. The models, fields, and relationships were reviewed and adjusted to match the actual schema requirements.

## 2. Debugging and Small Code Errors

**Tool Used:** ChatGPT / Codex

### Purpose

AI was used when small errors occurred during development. Instead of copying full solutions blindly, AI was used to understand what the error meant and how to fix it.

### Examples of Help

- Explaining Flask routing errors
- Fixing template rendering issues
- Understanding SQLAlchemy relationship errors
- Clarifying validation logic
- Troubleshooting Git and GitHub commands

### Personal Contribution

Each fix was tested manually after applying it. The application was checked through the browser to confirm that pages loaded correctly and database operations worked as expected.

## 3. User Interface Improvements

**Tool Used:** ChatGPT / Codex

### Purpose

AI was used to get suggestions for improving the look and organization of the user interface.

### Areas Improved

- Dashboard layout
- Bootstrap card spacing
- Button consistency
- Form readability
- Cool-toned color palette
- Navigation layout

### Personal Contribution

The final theme and visual direction were chosen manually. The app was designed to look like a clean staff/admin system for a pet adoption center rather than a customer shopping website.

## 4. Normalization and DBMS Concepts

**Tool Used:** ChatGPT

### Purpose

AI was used to review and better understand database normalization concepts required for the project documentation.

### Topics Discussed

- Functional dependencies
- 1NF, 2NF, and 3NF
- Update anomalies
- Insert anomalies
- Delete anomalies
- Relational schema explanation

### Personal Contribution

The final normalization explanation was checked against the actual database tables used in the application. The final schema was reviewed to make sure it matched the implemented project.

## 5. Documentation Support

**Tool Used:** ChatGPT / Codex

### Purpose

AI was used to help organize and improve the wording of project documentation.

### Documentation Areas

- README formatting
- User instructions
- AI acknowledgement wording
- Normalization report structure

### Personal Contribution

The final documentation was edited to match this specific pet adoption project. The wording was adjusted to reflect the actual features implemented in the application.

## Reflection

AI was used as a support tool during the project, similar to using documentation, tutorials, or programming help forums. It helped explain concepts and troubleshoot issues, but the final project required manual testing, editing, and understanding. The database design, application behavior, and final implementation decisions were reviewed and verified by the student.
