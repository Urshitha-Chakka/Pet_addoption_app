# AI Acknowledgement Log

AI was used only as a learning, debugging, and documentation assistant during this project. It was not used as a replacement for understanding the course material or for making final project decisions.

## How AI Assistance Was Used

AI assistance helped with:

- Explaining Flask routing, templates, and request handling concepts
- Explaining SQLAlchemy models, relationships, and database transactions
- Debugging small errors during development
- Improving UI styling while keeping the required cool color theme
- Clarifying normalization topics for the project documentation
- Formatting documentation in clear Markdown

## Student Review and Verification

All code was reviewed and tested by the student before submission. The student verified that the application features worked correctly, including login, CRUD operations, validation, dashboard statistics, relationship displays, and finalizing adoptions.

The database design and final implementation decisions were verified by the student. AI suggestions were reviewed critically and were not copied blindly.

## Academic Use Statement

The purpose of AI assistance was to support learning, troubleshooting, and documentation clarity. The final project represents the student's reviewed and tested implementation for a university DBMS course project.
